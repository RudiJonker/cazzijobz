PROJECT SUMMARY: cazzijobz
📱 App Overview
Name: cazzijobz (Casual Jobs)
Mission: Community-driven platform connecting people offering casual labor (Workers) with those needing tasks done (Employers)
Target Audience: Lower-income communities worldwide for casual work (gardening, cleaning, construction, domestic work, etc.)
Location: South Africa focused, globally scalable
Monetization: Google AdMob (future implementation)

🛠 Tech Stack
Frontend: React Native + Expo

Backend: Supabase (Auth, Database, Storage)

State Management: React Context + AsyncStorage

Navigation: React Navigation

IDE: VS Code

Testing: Windows 10 + Android USB

🏗 Architecture Foundation
API Call Strategy
text
Type A (Immediate): Signup, Initial Profile Completion, Critical Actions
Type B (Debounced): Profile Updates, Non-critical Changes
Timing Configuration:

Development: 1-minute timeout between Type B calls

Production: 5-minute timeout between Type B calls

Location: useProfileSync.js constants

AsyncStorage Strategy
Latest Data Wins: Subsequent changes overwrite previous pending changes

Automatic Retry: Failed syncs remain in storage for retry

Manual Trigger: Save button initiates timing checks

Storage Keys: last_profile_sync, pending_profile_changes
