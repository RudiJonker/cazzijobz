📱 App Overview
Name: cazzijobz (Casual Jobs)
Mission: Community-driven platform connecting Workers with Employers for casual labor
Target: Lower-income communities worldwide
Tech: React Native + Expo + Supabase + SafeAreaContext

🏗️ Architecture Foundation
API Strategy: Type A (Immediate) vs Type B (Debounced) calls
State Management: React Context + AsyncStorage
Navigation: React Navigation with Auth/Main stacks + role-based tabs
Database: Supabase (PostgreSQL) with RLS policies
Key Principle: NO AUTOMATIC API CALLS - manual refresh only

✅ COMPLETED FEATURES
1. Authentication System ✅
- Role selection (Worker/Employer)
- Email/password signup/login
- Session persistence

- Smart login with change merging

- Complete profile system with progress bar
- Profile picture upload to Supabase Storage
- Smart sync with Type A/B API strategy
- Local storage persistence across sessions

3. Job Management System ✅

id, email, role, is_profile_complete, is_admin, full_name, bio,

Jobs Table
id, employer_id, job_reference, description, category, location_city, 
location_suburb, address_text, scheduled_date, time_from, time_to, 
duration_hours, budget, budget_currency, status, applicant_count, 
created_at, updated_at

Applications Table (RLS POLICIES READY - NEEDS IMPLEMENTATION)
id, job_id, worker_id, status, applied_at, employer_notes, worker_notes

Storage Buckets
profile-pictures ✅ Working

🔄 Smart Synchronization System
Type A Calls (Immediate - User Decisions)
- User registration and login
- Job posting and editing
- Manual pull-to-refresh only

Type B Calls (Debounced)
- Profile field updates
- Preference changes
- Non-critical status updates

Spam Prevention System ✅ WORKING
- 60-second timeout between manual refreshes
- Persists across logout/login via AsyncStorage
- No automatic API calls - ever
- Stale data indicator after 5+ minutes
- Manual control only - user decides when to refresh
